## 🚀 Enable GitHub Pages

### Step 1: Go to Repository Settings

1. **Go to:** https://github.com/TanyaStrauss1/Spect-IT/settings/pages

2. **Configure:**
   - **Source:** Deploy from a branch
   - **Branch:** `main` (or `gh-pages` if you prefer)
   - **Folder:** `/ (root)`
   - Click **"Save"**

### Step 2: Wait for Deployment

- GitHub Pages will deploy automatically
- Takes 1-2 minutes
- You'll see a green checkmark when done

### Step 3: Get Your URL

**Your GitHub Pages URL will be:**
- `https://tanyastrauss1.github.io/Spect-IT/privacy-policy.html`

**Or if you have a custom domain:**
- `https://www.spect-it.com/privacy-policy.html`

## ✅ Quick Setup

1. **Enable GitHub Pages:**
   - Go to: https://github.com/TanyaStrauss1/Spect-IT/settings/pages
   - Select branch: `main`
   - Click "Save"

2. **Wait 1-2 minutes** for deployment

3. **Access your privacy policy:**
   - https://tanyastrauss1.github.io/Spect-IT/privacy-policy.html

4. **Use in App Store Connect:**
   - Enter the URL above in the Privacy Policy field

---

## 📝 Custom Domain Setup (Optional)

If you want to use `www.spect-it.com`:

1. **In GitHub Pages settings:**
   - Add custom domain: `www.spect-it.com`

2. **In your domain DNS:**
   - Add CNAME record pointing to: `tanyastrauss1.github.io`

3. **Wait for DNS propagation** (up to 24 hours)
