## 📏 LiDAR Distance Measurement System

### Core Features
1. **Accurate Distance Measurement**
   - Real-time LiDAR distance tracking
   - Target: 3.0m ±10% (2.7m - 3.3m)
   - Visual feedback bar (Red/Green/Red)
   - Live distance display

2. **Distance Locking**
   - Measure once, lock it in
   - Baseline distance stored
   - Continuous monitoring during test

3. **Movement Detection**
   - Tracks head/face depth over time
   - Threshold: ±5cm movement
   - Pauses test if movement detected
   - Repeats line for accuracy

4. **Letter Size Calibration**
   - Uses LiDAR distance for precise calculation
   - Visual angle: 5 arc minutes for 6/6 (20/20)
   - Formula: H ≈ D * tan(5/60 degrees)
   - Converts to pixels using screen specs

5. **Environment Checks**
   - Obstruction detection
   - Device angle validation
   - Lighting recommendations

6. **Stability Monitoring**
   - Real-time stability scoring
   - Movement warnings
   - Automatic line repetition

### Test Flow
1. Setup Phase
   - Position yourself at target distance
   - LiDAR measures distance automatically
   - Visual bar shows status
   - Lock distance when green

2. Test Phase
   - Continuous distance monitoring
   - Movement detection
   - Letter size calibrated to exact distance
   - Pause if movement detected

3. Results
   - Includes LiDAR calibration status
   - Stability score
   - Actual distance used
   - Clinical-grade accuracy note
