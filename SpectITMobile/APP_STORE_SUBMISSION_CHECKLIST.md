## Troubleshooting

### Build Not Available
- Check TestFlight tab for build status
- Wait for processing to complete (15-30 minutes)
- Upload new build if needed

### Screenshots Not Uploading
- Verify image dimensions are correct
- Check file format (PNG or JPEG)
- Try different browser

### Submission Button Grayed Out
- Check all required fields are complete
- Verify build is selected
- Check for error messages
