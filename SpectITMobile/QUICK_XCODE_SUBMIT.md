# 🚀 Quick Xcode to App Store - Reference Card

## ✅ Xcode Steps (Do This First)

### 1. Configure Signing
- Click **project** (blue icon) → Select **"SpectIT"** target
- **"Signing & Capabilities"** tab
- ✅ **CHECK "Automatically manage signing"**
- Select **Team: "Tanya Strauss (P7BPRR2MY3)"**
- Wait for **green checkmark** ✅

### 2. Select Target
- Top toolbar → Select **"Any iOS Device"** (NOT simulator)
- Scheme: **"SpectIT"**

### 3. Archive
- **Product → Archive**
- Wait **5-15 minutes**

### 4. Distribute
- **Window → Organizer**
- Select your archive
- **"Distribute App"**
- **"App Store Connect"**
- **"Upload"**
- Wait **5-10 minutes**

---

## ✅ App Store Connect Steps (After Upload)

1. Go to: https://appstoreconnect.apple.com
2. Sign in: **tanstrauss@gmail.com**
3. **My Apps → Spect-IT**
4. **App Store** tab
5. Wait for build to process (**15-30 minutes**)
6. **Select build**
7. **Complete required info** (see COMPLETE_SUBMISSION_GUIDE.md)
8. **Submit for Review**
